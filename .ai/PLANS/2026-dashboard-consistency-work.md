## 3. Открытая разработка (на следующий тред). Читать ДО начала.

### 3.1 Проблема (сформулирована владельцем)
- **Январь‑2022, «Фонд развития»:** в месячном документе начисления по кв были разными (только у 13 л/с по 6 000 —
  «парковка/освещение», а у кв 4,5,10,17 нет). Требуются «персональные начисления» (таких документов не видно).
- **Гипотеза владельца:** если начисление **не по всем л/с** → это фактически **персональное/особое** начисление.
  Иначе при пересоздании месячного документа по регулярным тарифам оно будет «раскидано» некорректно на всех.
- **Ключевой факт из кода:** дата открытия счёта при начислении НЕ учитывается
  (`calculate_accruals_preview`: все активные л/с × все услуги; фильтр только «нет тарифа/нулевой расход»).
  Значит у системы нет механизма отличать «новосёл без начисления» от «перс./особого сбора на часть л/с».

### 3.2 Принятые правила и решения (владелец, финальные)
- **Правило 1:** любое начисление НЕ по всем квартирам = персональное.
- **Правило 2:** любое начисление, где хотя бы в одной квартире индивидуальный (не общий для дома) тариф/сумма = персональное.
- **`opened_at` л/с (вариант ii, финальный) = дата первого начисления по л/с** (MIN(accrual_date) любого accruals_register-строка). По данным: 15 л/с = 2017-10 (Входящие остатки); кв8(id8) = 2017-11; кв4(id4) = 2017-12. Правило «не-по-всем» применяется к уже открытым на месяц л/с.
- **Направление 2 + вариант A:** учитывать `opened_at` в расчёте начислений ТОЛЬКО при создании/пересоздании месячных **вперёд**; историю не пересчитываем по датам, а лишь переклассифицируем не-по-всем/индивидуальные в перс-документы.

- **Шаг 4 (доп., ДАННЫЕ) — ВЫПОЛНЕНО 09.09:** восстановлены пропущенные начисления «Вывоз мусора» по кв13 (2020-07..2026-08, 74 мес / 114 500)
  миграцией `backend/migrations/recover_kv13_garbage_accruals.py` (dry/`--apply`, суммы=действ. исторической ставке 500/1000/1500/3000; вставка в существ. месячные доки + income в accounts_register + пересчёт).
  Контроль: 6 срезов начислений файл↔БД Δ=0; кв13 integrity consistent; долг по дому 1 434 089 / 17 л/с.
