# Черновик правил: разнесение «Расходы по дому» → новые статьи (сек. 2026)

Источник: сырые комментарии операций «Приход/Расход» в БД (`transactions.article_id = 2`,
778 записей). Правила — упорядоченное «первое совпадение» по нижнему регистру `notes`.

Контроль: сумма по всем операциям = **60 039 094**; каждая запись попадает ровно в одну статью.

## 3. Дополнительные правила «доуплотнения» остатка «Прочие расходы»

Вытащить из «Прочие расходы» в конкретные статьи (по смыслу комментария):

- → **Заработная плата персонала**: охрана/охранник/сторож — зарплаты и авансы (аванс за <месяц>/Кагай-персонал Кайрат/Ораз), ремонт сторожки/объектов охраны, ТВ/эл.плита для Кайрата, обогреватель для охраны.
- → **Обслуживание инженерных систем**: сварочные работы (сварка контейнера), ремонт уличных фонарей / электр. работы по месту, вызов электрика, пульт, пункиты «ТП», ремонт шлагбаума (*техобслуживание*), выдача/начисление по подряду на инж.
- → **Благоустройство территории**: доуплотняй: арычные лотки/доставка лотков, земля/грунт/чернозём во двор, песок и геотекстиль для песочницы, удобрения/озеленение/хвойные, баскетбольная стойка/кольцо/сетка, беседка и её КР (железо, мягкая кровля, работа по беседке/выключатель/навес), 3D-панели, гирлянды/украшения.
- → **Материалы и инвентарь**: счётчиковые приборы только как покупка устройств? (поток обслуживающей стороны) + см. п.2, хозтовары, мелкий инвентарь (заклепки/лента/метла), смесители/краны для полива.
- → **Безопасность и проверки**: экспертиза/топосъёмка, договоры по техобследованию газа/дымоходов.

### Остаток, который осознанно останется «Прочие расходы» (~1,08 млн / 43 записи)
Единичные управленческие/представительские (Наурыз, подарки, представительские, оформление приказа, ксерокопии), транспорт и ГСМ (бензин/такси), банковская комиссия, а также нечитаемые фрагменты (`[проект:2.0]`, пустые «За работу ?» без контекста).
